## Как продолжить работу

1. Открыть нужный репозиторий из таблицы.
2. Нажать **Code → Codespaces**.
3. Создать новый codespace или открыть существующий.
4. Прочитать `PROJECT_STATUS.md` — там записана текущая точка продолжения.
5. После работы сделать commit и push. Только после push изменения считаются сохранёнными.

## Правило организации

- Один самостоятельный проект — один репозиторий.
- `README.md` объясняет запуск и назначение проекта.
- `AGENTS.md` задаёт правила для Codex.
- `PROJECT_STATUS.md` хранит текущий результат и следующий шаг.
- `.env.example` содержит только названия переменных и безопасные заглушки.
- Настоящие секреты хранятся в GitHub Codespaces secrets, а не в репозитории.
